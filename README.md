# サービスサイト

## 制作背景
HTML/CSSの基礎から応用までを一通り身につけることを目的に制作しました。<br>
単純なレイアウトだけでなく、実務でよく使われる表現（斜めのボックスや吹き出し、擬似要素による図形表現など）を取り入れることで、デザインの再現力を高めることを意識しています。<br>
また、フォームやテーブル、ハンバーガーメニューなどの実用的なUIも組み込み、アクセシビリティやユーザビリティを考慮した構造設計の習得も目的としています。

---

## 使用技術
HTML, CSS, JavaScript

---

## 工夫した点
CSS設計を意識し、BEMやコンポーネント化、CSS変数の活用を行いました。<br><br>

曖昧なまま進めず、positionやtranslateの挙動を一つひとつ調べながら実装するようにしました。<br>
また、吹き出しや装飾要素についても仕組みを理解した上で再現し、自分の力で調整できるように意識しました。<br><br>

制作後もアクセシビリティや保守性について学習を続け、新たに得た知識をもとに既存のコードを見直しました。<br>
WAI-ARIAを活用したアクセシブルなハンバーガーメニューを実装しました。aria-expandedやaria-controlsなどをJavaScriptと連動させ、スクリーンリーダー利用者にも開閉状態が伝わるよう配慮しています。<br>
アクセシビリティとユーザビリティを意識し、ラジオボタン・チェックボックスをカスタマイズしながらもキーボード操作を維持できるフォームを実装を行いました。fieldset・legendによる適切なグループ化や、意味論に沿ったフォーム構造を採用しています。<br>
コメントアウトを追加・整理し、可読性と保守性を向上させました。

---

## 苦労した点
CSSのpositionやtransformの理解が不十分で、吹き出しや矢印などのレイアウト表現に苦手意識がありました。<br>
これまではなんとなくの指定やコピペに頼ってしまうことが多く、意図した位置に配置できない場面で詰まることがありました。

---

## 学んだこと
CSSやHTMLは見た目を整えるだけでなく、仕組みや意味を理解して使うことで、より正確で再現性の高いコーディングができると学びました。
